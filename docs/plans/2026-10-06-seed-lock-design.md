# 404 背包种子上锁与解锁

参考普通版 warehouse、BagPanel 和 itempb/corepb：复用 Item.locked 字段 9 与 ItemService.LockItems / UnlockItems，按背包实例 UID 操作，不使用本地锁定标记。

404 保留按物品 ID 合并的展示。originalItems 返回每个 UID 的 locked，合并项提供 lockedCount、unlockedCount 和全部锁定标记。种子卡片支持单种上锁/解锁；种子与全部分类支持批量模式、全选和确认。部分实例锁定时分别允许上锁剩余实例和解锁锁定实例。

后端校验账号权限、布尔状态、安全整数 UID、库存存在及种子类型；先校验全部实例，去重并跳过状态已一致的实例。getBagSeeds 排除锁定实例，覆盖现有单格、四格、背包回退及成长任务种植路径。出售、种子使用增加锁定检查，原有等级 >=200 的本地豁免和四格尺寸保持不变。

确认操作绑定原账号，切换账号取消待确认操作，请求中防止重复提交。成功操作后等待先前的背包查询完成，再读取最新状态。
