# 我的农场New 设计与实施计划

**Goal:** 在 404 的个人页新增我的农场New，迁移普通版土地卡片、紧凑缩放、定时刷新和单地块催全熟。

**Architecture:** 新面板与旧面板独立，复用 404 的账号、土地数据和农场接口。卡片使用普通版原组件，样式变量限定在新面板。施肥接口向后兼容，新增普通/有机类型和权威土地快照，以供逐次催熟判断。

**Tech Stack:** Vue 3、Pinia、TypeScript、Express、Node worker。

1. 复制普通版 LandCard 为 FarmNewLandCard，保留土地等级、状态、变异、倒计时、默认/紧凑显示。
2. 新增 FarmNewPanel，使用 404 组件实现手动刷新、可配置定时刷新、两种布局、普通/有机/催全熟操作。切页/隐藏/账号停止时停止定时刷新；请求去重；账号切换取消催熟。
3. 个人页在我的农场旁新增我的农场New，继续使用现有组件切换以保证不同时运行两个面板的定时器。
4. 抽出土地快照格式化方法，施肥读取 FertilizeReply 并返回最新土地与库存；兼容旧接口未指定类型时的单次有机肥操作。
5. 新面板催全熟沿用普通版：普通肥一次（允许时）、有机肥至成熟或无法继续；仅成熟成功后执行一键全收。状态无推进、肥料耗尽、切换账号、隐藏/离开页面时中止。
6. 固定夹具覆盖施肥类型/前置校验/回包格式化、进度/无推进/取消/肥料耗尽、刷新并发/切账号。完成类型检查和生产构建，重启 404 服务并验证静态产物。布局和真实账号交互由用户人工验收，不自动登录或操作真实账号。

## 验证结果

- 后端全套：403/403 通过，包含手动施肥、回包格式化、成熟判断与类型/权限边界。
- 前端本次功能及管理登录相关测试：24/24 通过，包含刷新去重、账号切换、权威快照防旧数据覆盖、无推进/库存耗尽/取消中止。
- 改动文件 ESLint、vue-tsc 类型检查与 Vite 生产构建通过。
- 前端全量测试另有 3 个已有 wx-login.test.cjs 失败，该测试与对应 wx-login store 未改动。保留原状。
- 404 已重启到 3007，普通版仍在 3008。HTTP 与新个人页构建资源检查通过。
- 未登录或操作真实账号；土地布局、缩放观感和催全熟实际交互由用户人工确认。

## 后续调整

- 普通化肥只有剩余次数明确大于 0 时显示；已用过、次数未知、非生长期均隐藏。手动施肥和催全熟复用同一判断。
- 新面板增加收获、一键务农、种植、升级土地、一键全收、一键铲除六个按钮，复用现有 404 接口并保留确认与并发保护。确认绑定原账号，切换账号不能误执行；一键铲除明确提示不可恢复。
- 一键铲除后清理施肥快照并重新读取土地；业务失败不能显示成功。

## 个人页布局调整

- 概览的账号、资产、化肥/图鉴三张卡片提取为共享展示组件；个人页面顶部复用，页签切换时保持可见。
- 个人页整页滚动；顶部卡片与页签独立排列，移动端自动换行。
- 新农场工具栏区分标题、刷新/定时/布局控制，状态统计和批量操作在下方排列；按钮统一为中性色，一键全收突出主题色，铲除使用红色描边。土地卡片保留已确认的样式。
- 资源刷新包含并发去重、账号切换隔离、页面隐藏/卸载暂停；施肥结束后刷新化肥库存，图鉴按低频率更新。

## 单块土地铲除入口

已有作物的主土地右上角增加铲除按钮，复用原农场 removePlant 和确认弹窗。空地、未解锁土地与四格作物的从属土地不提供入口；合种徽标下移避免遮挡。执行前核对当前账号、作物和季数，复用忙碌状态防止与施肥及批量操作重叠。单地铲除成功清除该地施肥快照并刷新，业务失败不报成功。相关离线前端测试 31 项全部通过。
